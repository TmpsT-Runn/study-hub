About & Install

Right now this is a single page that runs in your browser and saves to this browser only. It is not installable and it does not sync between devices yet.

Installing on a phone or desktop (later)

To become an installable app, this page would need to be hosted at a secure (https) address with a web app manifest (name, icons, colors) and a service worker for offline use. After that, supporting browsers offer “Install” on desktop (Chrome/Edge) or “Add to Home Screen” on phones (Safari on iPhone, Chrome on Android). The layout is already responsive and touch-friendly to prepare for this.

Syncing across devices (later)

Sync needs user accounts (sign-in), a server and database to hold each person’s decks, and rules for resolving edits made on two devices. The code keeps all saving behind one storage interface (load, save, clear) so a server-backed version can replace the browser one without rewriting the rest of the app. Until then, use JSON backups to move data by hand.

AI-generated cards (later)

Today cards come from simple built-in rules. AI-written cards would need sign-in and a server that calls an AI model on your behalf, because keys and usage limits cannot be kept safely in a web page. Your notes would be sent to that server, so a privacy notice and consent would be required.
